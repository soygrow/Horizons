# 详情页差异化方案（创业机会雷达）

**文档版本：** V1.0（已确认）
**状态：** 实施中
**决策结论（2026-10-22 确认）：**
1. 五个创业模块全做。
2. 为 picvo.ai 跑真实数据管线（自建爬虫 + PH + DataForSEO + LLM），替换哥伦布种子数据。
3. AI 自动生成内容，不做人工审核。
4. 页面信息变化 → UI 重新设计排版（浅色主题先行，深色后置）。

---

## 一、定位转变

从「站点分析报告」（哥伦布，研究者视角）→「**创业机会雷达**」（面向想创业的个人开发者）。

受众诉求不是"这个站的数据"，而是「**我能不能做、值不值得做、怎么做、能抄什么**」。

## 二、差异化维度

### 2.1 保留哥伦布骨架 + 「创业者 so-what」
五大区结构不变，每个区块末尾加一行创业者结论。

### 2.2 五个创业模块（哥伦布没有，差异化主体）

| 模块 | 字段 | 价值 |
|------|------|------|
| ① 机会评分卡 `opportunity` | 综合分 + 5 分项（竞争度/变现成熟度/增长可复制性/技术门槛/启动成本）+ 结论「值得抄/谨慎/别碰」 | 一眼判断值不值得下场 |
| ② 变现蓝图 `monetizationBlueprint` | 商业模式 + 定价阶梯 + 收款信号检测 + 起步定价建议 | 回答"怎么赚钱" |
| ③ 增长复盘 `growthPlaybook` | 冷启动 + 有效渠道 + 「值得抄/是坑别踩」双栏 | 少踩坑 |
| ④ 启动蓝图 `buildBlueprint` | 技术栈 + 第三方 API/模型 + MVP 范围 + 周期 + 月成本 | "最小版本只要 X" |
| ⑤ 灵感触发 `ideaSparks` | 3~5 个变体点子（换场景/换人群/换商业模式/换语区）+ 为什么有机会 | 付费转化核心钩子 |

### 2.3 数据维度差异化（补哥伦布没有的创业者信号）
1. Product Hunt 表现（votes/comments/上线时间）
2. 收款信号（Stripe/Paddle/LemonSqueezy 跳转检测）
3. 开源信号（GitHub stars）
4. 口碑代理（品牌词搜索量 + 直接访问占比）
5. 竞争格局（同类数量/集中度，LLM 归纳）

### 2.4 付费墙设计
- 免费：机会评分总分 + 变现蓝图前半 + 灵感点子标题
- 付费：分项打分明细 + 增长复盘「抄/别抄」+ 灵感点子完整展开

## 三、数据生成逻辑（用自己的方式，不复制哥伦布）

| 数据 | 来源 | 成本 |
|------|------|------|
| 页面结构 / 技术栈 / 结构化数据 / 收款检测 / 定价线索 | 自建爬虫（`sources/site-audit.ts`） | 免费 |
| 热度信号（PH votes/comments/launchedAt） | Product Hunt API | 免费 |
| 搜索流量 / 关键词 / 国家 / 趋势 / 外链 / whois | DataForSEO（按次） | 单站 $0.02~0.2 |
| 中文描述 / 标签 / AI 解读 / 创业洞察①②③④⑤ | DeepSeek LLM | 低价 |

> 所有文字均 LLM 基于「我们自己的采集数据」生成；指标来自我们自己的 DFS/爬虫/PH 采集。

## 五、picvo.ai 试点结果（数据口径说明）

**重要：** DFS 与哥伦布（SimilarWeb）数据口径不同，绝对值差异属正常，非数据错误：

| 指标 | 哥伦布（SimilarWeb） | 我们（DataForSEO） | 说明 |
|------|---------------------|-------------------|------|
| 月访问量 | 5.5K | ≈11（搜索流量） | DFS 只覆盖搜索流量口径，且对新站/长尾估算偏低 |
| 自然搜索流量 | 1.6K | ≈11 | 同上 |
| 渠道占比 / 国家分布 | 有 | 待接入 | DFS 无法提供，诚实占位 |
| 外链 | 300 / 292 | 待接入 | picvo 外链过少，DFS backlinks 未收录 |
| 域名权重 DR | 0 | 待接入 | DFS 权重与 DR 非同一指标 |

> 结论：流量类绝对值的权威性 SimilarWeb 占优（商业化后再补），当前 DFS 数据**诚实呈现、明确标注口径**，不编造。页面结构（H1~H3=1/7/29）、技术栈（Next.js/Vercel/GA/GTM/Webpack）为自建爬虫真实采集，与哥伦布一致，验证管线正确。
