## 三、字段 ↔ 数据源映射（DataForSEO 字段分析）

> 供应商结论维持 `4-数据源与字段方案.md` 第六章：DataForSEO 首选（按次计费）。下面按哥伦布字段逐项给出可达成路径与口径差异。

| 哥伦布字段 | DataForSEO 端点 | 可达成 | 口径说明 |
|-----------|----------------|:---:|----------|
| 月访问量（总） | ❌ 无 | ⚠️ 部分 | DFS 只有**搜索流量**（organic+paid etv），无直接/社媒/外链口径。替代：`bulk_traffic_estimation` etv，**改标「搜索流量」或以 DFS 口径展示并加注** |
| 环比增长 | `historical_rank_overview` 相邻两月 etv | ✅ | 基于搜索口径计算 |
| 自然搜索流量 | `bulk_traffic_estimation` → `metrics.organic.etv` | ✅ | 已实现（scripts/fetch/sources/dataforseo.ts） |
| 自然搜索占比 | organic / (organic+paid) | ⚠️ | 分母不同：哥伦布是全渠道；我们只能给「搜索口径占比」，UI 加注 |
| 域名权重 DR | ❌ 无 DR（Ahrefs 指标） | ⚠️ | 替代：Backlinks Summary API 的 `rank`（DFS 自有 0~1000 权重），UI 标「域名权重」不冒充 DR |
| 注册时间 | Domain Analytics `whois/overview` | ✅ | WHOIS 创建时间 |
| 流量趋势（7 个月） | `historical_rank_overview` 按月 etv | ✅ | 搜索口径（总=organic+paid，自然=organic） |
| 流量结构 10 渠道 | ❌ | ⚠️ | DFS 只能拆 付费搜索/自然搜索 两项；其余 8 渠道**待接入**（诚实占位） |
| 主要国家 | `domain_rank_overview`（按 location） | ✅ | 搜索流量口径 |
| 互动指标（跳出/页均/停留） | ❌ | ❌ | SimilarWeb 独有，**待接入**（Commercialize 后评估） |
| 全球/国内排名 | ❌ | ⚠️ | Tranco 全球排名兜底；「国内排名」暂无来源 |
| 外链总数/引荐域名/dofollow% | Backlinks `summary`（backlinks/refdomains/dofollow） | ✅ | 明细 `backlinks/backlinks` 可取 Top N（含来源 DR、锚文本） |
| 关键词/搜索量/CPC/竞争/流量 | `ranked_keywords`（search_volume/cpc/competition + keyword etv） | ✅ | competition 为 0~1 数值，需映射 LOW/MEDIUM/HIGH；「流量」列 = 单词 etv |
| 页面结构/SEO 拆解 | 自建爬虫（免费） | ✅ | title/meta/H1-3/内外链/图片/结构化数据/字数/语言 |
| 技术栈/分析工具 | 自建指纹（免费） | ✅ | 已有 techstack.ts |
| 定价线索 | 爬 /pricing + LLM（免费） | ✅ | 已有 pricing.ts |
| AI 解读 ×8 段 | LLM（GLM-4-Flash） | ✅ | 新增 detail-insight 任务：输入全量指标 → 输出 8 段结构化 JSON |

**结论：** 哥伦布 24 类字段中，DFS 直接覆盖 9 类、替代口径 5 类、免费自建 6 类、确无来源 4 类（互动指标、渠道占比主体、国内排名、总访问量口径）。UI 全量渲染 + `dataStatus: live | pending` 占位，不编造。

**成本控制（用户要求）：** picvo.ai 单站试点先行——DFS 各端点对单域名成本约 $0.02~0.2，试点 < $1；确认页面验收后再批量跑其余 172 站（估算 $4~35，跑前再确认）。

## 四、双主题设计（浅色 / 深色）

- 实现方式：CSS 变量语义层。`globals.css` 中把现有 `--color-*` token 改为 `@theme inline` 引用 `:root`（浅色默认）/ `.dark`（深色覆盖）两套变量；现有组件类名（`bg-surface text-ink border-border` 等）**无需改动**即自动适配。
- 浅色为详情页默认观感（对齐哥伦布浅色），深色沿用现有品牌（近黑画布 + 蓝紫主色）。
- 新增语义色：`frost`（Hero 浅灰蓝底）、`ocean/ocean-deep/ocean-hover`（AI 解读强调）、`success`（正向增长）、`data-1..5`（条形色阶，两主题各一组）。
- 切换：`ThemeToggle` 客户端组件（sun/moon），localStorage 持久化 + `<html>` 内联脚本防闪烁（FOUC），默认跟随系统、无偏好时浅色。

## 五、i18n 设计（中文先行，英文后置）

- `apps/web/src/lib/i18n/`：`zh.ts`（全量字典）+ `en.ts`（同构 Partial，缺失回落 zh）+ `index.ts`（`getDict(locale)`）。
- 详情页全部文案走字典（区块标题、副标题、AI 解读栏目标签、指标名、渠道名、按钮、占位文案）；数据内容（AI 解读正文、描述、标签值）属于**数据**，存 `zh` 与 `en` 双语字段由数据管线产出（本期只产中文）。
- 其余页面（榜单/首页）文案后续统一迁移字典；路由不加 locale 前缀，切换由 header 的语言按钮驱动（英文版最后实现）。
