### 3.2 S1 主力：Product Hunt 展开

- 接口：PH GraphQL `POST https://api.producthunt.com/v2/api/graphql`，Developer Token `Bearer`（已验证）。
- 拉取：AI 相关 topic 双轨 `order: VOTES`（热门）+ `order: NEWEST`（新发布）；topic 清单逐步扩展。
- 字段：`name/tagline/description/website/votesCount/commentsCount/createdAt/topics`。
- 阻塞与解法：`website` 返回 `/r/xxx` 跳转 → 用 OAuth 授权码换 scope token 拿真实 `website`，或 Playwright 无头跟随重定向（与截图服务共用）。

### 3.3 目录合规边界

- theresanaiforthat / aitools.fyi：无官方 API，仅作「人工发现线索」，不自动爬。
- futurepedia.io：有付费 API，商业化后评估。
- 无论来源，最终字段以「自建爬虫访问官网 + PH 官方 API」产出为准，来源只负责「发现域名」。

## 五、数据模型 V4

### 5.1 AI 工具榜 `AITool` Schema

```ts
export type PricingModel = "free" | "freemium" | "paid";

export interface AITool {
  id: string;
  name: string;
  domain: string;                 // 注册域（去重主键）
  url: string;
  description: string;            // 中文一句话
  descriptionSource: "ai" | "manual";
  categories: AIToolCategory[];
  segmentLabel?: string;          // 细分赛道
  industry: "人工智能";
  heatScore: number;

  phUpvotes?: number | null;      // 真实产品热度信号（PH）
  phComments?: number | null;
  trancoRank?: number | null;     // 全球排名（免费替代）

  launchedAt?: string;            // PH createdAt
  launchedAtEstimated?: boolean;
  firstSeenAt: string;
  collectedAt: string;

  verified: "verified" | "pending";
  sourceType: "producthunt" | "manual" | "submitted" | "yc" | "directory";
  sourceUrl: string;
  phUrl?: string;

  pricingModel?: PricingModel;
  longDescription?: string;
  tags?: string[];
  pricing?: { plan: string; price: string; desc?: string }[];
  techStack?: string[];
  contact?: { email?: string; socials?: { label: string; url: string }[] };
  screenshotUrl?: string;
  heatHistory?: { date: string; score: number }[];

  // P4 付费字段（本期不采集不渲染）
  traffic?: { visits: number; durationSec?: number; pagesPerVisit?: number; bounceRate?: number };
  trafficHistory?: { date: string; visits: number }[];
  channels?: { social: number; direct: number; search: number; referral: number; email: number };
  geoDistribution?: { country: string; share: number }[];
  keywords?: { term: string; volume?: number; cpc?: number; competition?: string }[];
  priceHistory?: { date: string; plans: { plan: string; price: string }[] }[];
}
```

> 说明：移除 `githubStars`（那是 GitHub 榜字段）；`sourceType` 去掉 `github`、新增 `producthunt/yc/directory`。

### 5.2 热度公式（真实产品版）

- `heatScore = norm(phUpvotes)*0.5 + norm(phComments)*0.2 + recency*0.3`
- 接入流量数据后追加 `norm(visits)*0.2` 并重调系数。
- 涨幅 = 最近两次快照 diff。

### 5.3 存储与快照

- 榜单数据面维持 `content/aitools.json`（SSG）；规模 1000+ 后分片 `content/tools/*.json`。
- 快照 `content/snapshots/heat-YYYY-MM-DD.json` 每日 append，构建期合并进 `heatHistory`。
- 用户/订阅在 D1（不变）。

## 六、付费数据供应商对比分析（重点）

### 6.1 需求画像

面向 3000 个域名批量，需两类数据：
- **流量类**：月访问量、渠道占比、国家分布、全球排名、流量趋势
- **关键词类**：搜索量、CPC、竞争度、相关关键词

### 6.2 候选供应商全景对比

| 供应商 | 流量估算 | 渠道/国家 | 关键词 | 计费模式 | 起步价 | 批量友好度 | 结论 |
|--------|:---:|:---:|:---:|------|------|:---:|------|
| **DataForSEO** | ✅ Traffic Analytics | ✅ | ✅ Keyword Data | 按次充值 | ~$20 | ★★★ | **首选** |
| **SE Ranking** | ✅ | 部分 | ✅ | 订阅（API 含计划） | ~$55/月 | ★★ | 备选 |
| Serpstat | ✅ | 部分 | ✅ | 订阅 | ~$69/月 | ★★ | 备选 |
| SpyFu | 弱 | ❌ | ✅ 强 | 订阅 | ~$39/月 | ★ | 仅关键词 |
| Ahrefs | ✅ | ❌ | ✅ 强 | 订阅 | ~$129/月 | ★★ | 偏 SEO |
| SEMrush | ✅ | ✅ | ✅ | 订阅 + units | ~$139.95/月 | ★★ | 全栈贵 |
| **SimilarWeb** | ★最权威 | ★最权威 | ❌ | 企业 API | $149/月起，API 数千/年 | — | 商业化后 |

> 价格据 2026 年 3~7 月多个独立对比源，实际以官网为准。

### 6.3 关键结论

1. **DataForSEO 为何首选**：
   - 按次计费、$20 起充值、零订阅锁定；
   - **一个供应商同时覆盖「流量估算 + 关键词」两类需求**；
   - 订阅制工具（SEMrush/Ahrefs）有月度查询配额，批量拉 3000 域名容易撞墙；按次充值天然适合一次性批量；
   - 代价：估算模型精度略低于 SEMrush/SimilarWeb，但结构完整、够用。

2. **SE Ranking 是唯一值得认真考虑的备选**：
   - 2026 年被多篇对比列为 DataForSEO 直接竞品，API 完整（关键词/流量/排名/审计）；
   - 若后续要「每日全量刷新」这类持续高频调用，订阅制可能比按次更划算；首版批量拉取则不如按次灵活。

3. **SimilarWeb 留到商业化后**：流量数据的行业标杆（渠道/国家/排名最准、哥伦布同款），但 API 企业级数千美元/年，现阶段性价比低。

### 6.4 最终建议

1. **首版**：所有字段 UI 全量展示，付费字段数值用「待接入」占位（见 6.5）。
2. **接数据时**：先用 **DataForSEO 小额充值（$20 起）** 覆盖「流量估算 + 关键词」，跑通 UI 与数据价值，成本几十美元内。
3. **有收入后**：评估升级 **SimilarWeb**（权威流量），替换 DataForSEO 的流量部分。

### 6.5 首版字段占位策略（已确认）

- 详情页所有区块**全部渲染**（概览/流量/渠道/国家/关键词），付费字段未接入时显示「待接入」占位，**不隐藏、不编造**。
- 已接入的免费字段（PH 热度、Tranco 排名、热度曲线）正常显示。
- 用字段级标记 `dataStatus: "live" | "pending"` 驱动前端占位态渲染。


### 7.2 LLM 增强管线

- 模型：GLM-4-Flash（免费档）或同级低成本。
- 任务：`classify`（11 类）、`describe`（≤40 字中文）、`longDescribe`（80~150 字）、`extractPricing`（plan 结构化），单次调用合并输出 JSON。
- 量级：3000 条 × ~1k tokens ≈ 300 万 tokens，免费额度内可完成首轮；5% 人工抽检回流。

### 7.3 调度

- GitHub Actions cron：每日快照 + 每周全量 enrich → commit → Cloudflare Git 集成自动重建。
- Secret：`PH_TOKEN`、LLM key 入 GitHub Secrets。

### 7.4 GitHub 工具榜（独立频道）

- 数据源：现有 GitHub Search API（`topic:ai-tool` 等），字段模型独立（`stars/forks/language/repo desc`）。
- 现有 `content/aitools.json` 8 条迁入 `content/github-tools.json`；新增 `/github` 路由复用榜单表格组件，列改为 stars/语言/最近更新。

## 九、合规与风险

| 风险 | 缓解 |
|------|------|
| PH 重定向被 Cloudflare 拦 | OAuth 流程 / Playwright 无头跟随 |
| 目录站 ToS | 只用有 API/许可的源，其余仅人工线索 |
| 流量数据缺失 | 首版诚实隐藏，不编造；分阶段接 DataForSEO |
| 头部榜单质量 | 人工编辑 Top 300 + 抽检机制 |
| 数据量拖慢构建 | JSON 分片 + 增量构建；超阈值迁 D1 |
| PH 热度≠真实流量 | 明确标注「热度（PH）」，与「访问量」区分呈现 |
